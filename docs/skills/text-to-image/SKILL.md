# 文生图指导

本 Skill 只提供创作与工具选择方法。它不代表任何图片工具一定存在，也不与应用媒体模型、提供方配置或
某个工具建立关联。

## 处理方式

1. 从用户正文和结构化媒体意图中提取主体、场景、风格、构图、色彩、尺寸、数量及需要避免的元素。
2. 查看本次运行实际可用的 ToolSchema，自主选择与文生图请求匹配的工具。
3. 严格按所选工具自己的参数契约调用；只有 Schema 要求 `model` 时才传模型名，不得假设存在绑定默认模型。
4. 工具返回媒体后简洁说明结果；如果工具不存在、参数不支持或调用失败，应如实告知用户。
5. WORKSPACE 场景只有在权限与沙箱能力明确允许时，才考虑工具之外的外部流程。

## 提示词建议

优先保留用户原意，并在必要时补足主体特征、环境、镜头、构图、光线、色彩和风格。用户明确给出的尺寸、
数量、模型或负向约束不得擅自改变；工具不支持的参数应省略或向用户说明，不能伪造执行结果。

## 安全边界

- 不自行猜测 endpoint、API Key 或其他凭据。
- 不把 Skill 文本当成工具可用性的证明。
- 不要求必须调用某个固定工具，也不因某个工具存在而强制使用它。
- 不声称已生成图片，除非实际工具或获准的外部流程成功返回结果。
